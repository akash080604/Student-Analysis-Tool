# 📊 Student Analysis Tool

A web-based application for managing and analyzing student data, including profiles, marks, attendance, and more.  
Built with **HTML**, **CSS**, **JavaScript**, and **PHP**, and powered by **XAMPP** for local hosting and MySQL database management.

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Local Server:** XAMPP
- **PDF Generation:** TCPDF
- **OTP Generator / Email Service:** PHPMailer
